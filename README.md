## 项目概述

这是一个基于 .NET 10 Web API 的个人博客系统后端项目。通过这个项目，你将学习到：

- RESTful API 设计
- Entity Framework Core 数据访问
- JWT 身份认证
- 数据库设计与关系映射
- API 文档生成（OpenAPI/Swagger）

## 第二阶段：数据库设计与实体建模

### 目标

设计博客系统的数据库结构，创建实体类

### 核心实体分析

#### 1. 文章（Post）实体

你需要考虑以下字段：

- 文章的唯一标识
- 文章标题
- 文章内容
- 创建时间
- 更新时间
- 发布状态（草稿/已发布）
- 作者关联
- 分类关联
- 标签关联

#### 2. 分类（Category）实体

- 分类的唯一标识
- 分类名称
- 分类描述
- 与文章的关系

#### 3. 标签（Tag）实体

- 标签的唯一标识
- 标签名称
- 与文章的关系（思考：一篇文章可以有多个标签，一个标签可以对应多篇文章，这是什么关系？）

#### 4. 用户（User）实体

- 用户的唯一标识
- 用户名
- 邮箱
- 密码（思考：密码应该如何存储？）
- 角色（管理员/普通用户）
- 创建时间

#### 5. 评论（Comment）实体

- 评论的唯一标识
- 评论内容
- 评论者信息
- 关联的文章
- 创建时间
- 父评论ID（思考：如何实现评论的回复功能？）

### 关系梳理

1. **用户与文章**：一个用户可以写多篇文章，一篇文章属于一个用户
2. **文章与分类**：一篇文章属于一个分类，一个分类下有多篇文章
3. **文章与标签**：多对多关系
4. **文章与评论**：一篇文章有多条评论，一条评论属于一篇文章
5. **评论与评论**：自引用关系（评论的回复）

### 你需要做的事情

1. **创建实体类文件夹和实体类**
   - 按照上面的分析，创建对应的实体类
   - 思考：实体类需要哪些特性（Attribute）？
   - 提示：主键、外键、导航属性、数据约束
2. **配置实体关系**
   - 思考：EF Core 中如何配置实体关系？
   - 提示：有两种方式，一种是在实体类上用特性，另一种是使用 Fluent API
   - 建议：使用 Fluent API 在单独的类中配置，这样更灵活
3. **创建数据库上下文（DbContext）**
   - 思考：DbContext 的作用是什么？
   - 需要做的事情：
     - 创建继承自 DbContext 的类
     - 为每个实体定义 DbSet
     - 在 OnModelCreating 中配置实体关系

## 第五阶段：API 控制器开发

### 目标

实现博客系统的核心 API 接口

### 控制器规划

#### 1. 文章控制器（PostsController）

需要实现的接口：

- 获取文章列表（支持分页、排序）
- 获取单篇文章详情
- 创建文章（需要登录）
- 更新文章（需要登录，只能更新自己的文章）
- 删除文章（需要登录，只能删除自己的文章）
- 根据分类获取文章
- 根据标签获取文章
- 搜索文章

思考：

- 分页应该如何实现？
- 搜索功能应该如何设计？
- 如何验证用户权限？

#### 2. 分类控制器（CategoriesController）

需要实现的接口：

- 获取所有分类
- 获取分类详情
- 创建分类（管理员）
- 更新分类（管理员）
- 删除分类（管理员）

#### 3. 标签控制器（TagsController）

需要实现的接口：

- 获取所有标签
- 获取标签详情
- 创建标签
- 删除标签

#### 4. 评论控制器（CommentsController）

需要实现的接口：

- 获取文章的所有评论
- 发表评论（需要登录）
- 删除评论（管理员或评论作者）

#### 5. 用户认证控制器（AuthController）

需要实现的接口：

- 用户注册
- 用户登录
- 获取当前用户信息

### 你需要做的事情

1. **创建控制器基类（可选）**
   - 思考：是否有公共逻辑可以提取到基类？
2. **实现各个控制器**
   - 按照 RESTful API 规范设计路由
   - 正确使用 HTTP 方法（GET、POST、PUT、DELETE）
   - 返回合适的 HTTP 状态码
   - 添加适当的特性（路由、验证等）

## 第六阶段：身份认证与授权

### 目标

实现 JWT 身份认证，保护需要登录的接口

### 你需要了解的概念

1. **JWT 是什么？**
   - 思考：JWT 的结构是怎样的？
   - 提示：Header、Payload、Signature
2. **认证 vs 授权**
   - 认证：验证你是谁
   - 授权：验证你能做什么

### 你需要做的事情

1. **配置 JWT 认证**
   - 在 Program.cs 中添加认证服务
   - 配置 JWT 验证参数
   - 思考：密钥应该放在哪里？
2. **实现 JWT 生成服务**
   - 创建接口和实现类
   - 实现根据用户信息生成 JWT 的方法
3. **保护 API 接口**
   - 思考：如何标记需要登录的接口？
   - 思考：如何实现角色授权（管理员 vs 普通用户）？
4. **获取当前用户信息**
   - 思考：在控制器中如何获取当前登录用户的信息？
